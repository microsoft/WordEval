# Contributing

This project welcomes contributions and suggestions. Most contributions to
Microsoft open source projects require agreement to a Contributor License
Agreement (CLA).

For details, see https://cla.opensource.microsoft.com/.

Please also review the Microsoft Open Source Code of Conduct:
https://opensource.microsoft.com/codeofconduct/.

## Security Issues

Do not report security vulnerabilities through public GitHub issues. Report
security issues to the Microsoft Security Response Center:
https://msrc.microsoft.com/report.
